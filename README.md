# VenvCreate
**A comprehensive tutorial to creating a Python Virtual Environment with `venv`!**

## Create a virtual environment
In this tutorial, we will create a Python virtual environment called `venv`!

Navigate to the desired directory and run this command in your terminal to set up your virtual environment:

```
python -m venv venv
```
A folder called `venv` is created! This folder will contain all the files needed to create a virtual environment in your directory!

Activate the virtual environment:
```
venv\Scripts\activate
```

You can now install Python packages with `pip` without polluting your system!

### NOTE:

The name of the virtual environment folder can be named whatever you want!

But make sure you add the name of the folder to your `.gitignore` **BEFORE** you create it **if your using version control!**
