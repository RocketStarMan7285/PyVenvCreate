# VenvCreate
**A comprehensive tutorial to creating a Python Virtual Environment with `venv`!**

## Create a virtual environment
In this tutorial, we will create a Python virtual environment called `venv`!

Run this command in your terminal to set up your virtual environment:

```
python -m venv venv
```
Activate the virtual environment:
```
venv\Scripts\activate
```
